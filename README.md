# sources

A community-maintained list of comic and novel sources. To use it, paste this
address into a reader that accepts source lists:

```
https://raw.githubusercontent.com/inkcrate/sources/main/community.json
```

## What this is

`community.json` lists each source's name, language and site, and the bundle
that reads it, with that bundle's SHA-256. The bundles are plain JavaScript.
They can make HTTP requests and parse HTML, and nothing else. Most sites run
one of a few website engines, so many sources share one bundle.

## What this is not

This list is **unsigned**, and nobody vouches for it. Nothing here stores,
mirrors or serves any comic or novel: requests go from the reader's device
straight to each site. No warranty of any kind. Sites break, disappear and
change hands without notice.

## A source is broken

Open an issue with the source's name and what you saw.
